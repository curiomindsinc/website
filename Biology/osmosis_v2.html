🧂 Sucrose solution

Method

  1. Cut 6 potato strips of the same size. Blot dry and weigh each one.
  2. Place one strip in each sucrose solution. Press Start to soak for 30 minutes.
  3. Remove each strip, blot dry and weigh again.
  4. Plot % change in mass against concentration. Find where the curve crosses zero.
